# CRAFT OEM 営業の自動化

目的：月10件の受注に向けて、営業の「調べる・書く・つくる」をAIで回す。**送る・お金・実物の判断は人がやる。**

## 使うもの

- 営業リスト（Claude Sheets）：https://claude.ai/artifact/JTQiKU86aPatA93F8pjYLH
  - 読み書きは Claude Docs コネクタ（`guide topic.sheets` を先に読む）。シート「営業リスト」、列 A〜L：
    優先度 / 区分 / 会社・ブランド / 状況 / 提案するもの / どんな相手か / URL（出典） / 次にやること / 最終連絡日 / メモ / DM文面 / サンプル案
  - シート「参考（競合・外注先）」は競合なので、ここから営業先を選ばない。
- サンプル案の画像：`node scripts/craft-sales/mock.mjs --brand "<名前>" --item wallet|cardcase|keycase --colors black,camel,ivory --out <パス>`
  - ロゴ画像があれば `--logo <ファイル>`。相手のロゴは公開ページから取得した画像を使い、提案以外に使わない。
  - `scripts/craft-sales/photos/` に実物のベース製品の写真が登録されていれば、写真にロゴを合成する（登録方法は同フォルダの README）。写真があるアイテム・色を優先して使う。
- DM の型：`scripts/craft-sales/templates.md`

## 引数

`/craft-sales [件数] [区分]`。件数の既定は 20。区分は「インフルエンサーブランド」「新興ブランド」「クリエイター」「紹介パートナー」のどれか、なければバランスよく。

## 手順

1. **リストを読む**。既にある名前は重複させない。
2. **探す**（WebSearch、件数ぶん）。狙うのは「ファンや売れ行きはあるが、革小物を自分で作れない相手」：
   - 2025〜2026年にデビュー・初ポップアップ・初の路面店をしたアパレル・雑貨ブランド
   - 自分のブランドやグッズを持つインフルエンサー・YouTuber（ファッション、ランニング、キャンプ、釣り、ゴルフ、ガジェットなど）
   - インフルエンサーの事務所、複数ブランドの運営会社、グッズ販売サービス（紹介パートナー）
   - **入れない**：革製品メーカー・工房・革小物ブランド（競合）、すでに革小物を出している相手、自社ブランド（ASIANARTS／アジアンアーツ、DAYSART／デイズアート、カリスポシェ）。
   - 名前は出典ページで確かめたものだけ。推測で埋めない。出典URLを G 列に入れる。
3. **革小物の有無を確認**。公式サイト・オンラインストアで財布・カードケース・キーケース・バッグ（革）を探す。
   - なし → 状況「革小物なし」、あり → 状況「見送り」（メモに理由）、確かめられない → 「未確認」のまま。
4. **優先度**：A＝始めて1〜2年以内で勢いがある／ファン向け商品を出している、B＝それ以外の候補、C＝規模が大きく既存の取引先がありそう。
5. **DM文面**（状況「革小物なし」の行だけ）：`templates.md` の初回＋追いかけ2通を、相手の商品・発信内容に合わせて書き、K 列へ。誇張しない。実績は下の「言ってよいこと」だけ。
6. **サンプル案**（優先度 A の行だけ）：mock.mjs で画像をつくり、`out/craft-sales/<日付>/` に保存して L 列にファイル名を入れる。アイテムは相手に合うもの（ランナー→キーケース、コスメ→カードケース等）。
7. **報告**：足した件数、革小物なし／見送り／未確認の内訳、優先度Aの一覧、送信待ちの DM 数。

## 言ってよいこと（実績）

- 革製品づくり20年、タイの提携工場
- クラファン累計支援額 1億円（自社ブランドの実績）
- 小ロット 50個〜、カラー別OK、オリジナル設計（型紙・抜き型から）
- 打ち合わせはすべてチャット
- 料金はまだ例の段階なので、DMに金額を断定して書かない（「50個で○○万円〜が目安」は担当者が確定してから）

## してはいけないこと

- **DMやメールを自動で送らない。** Instagram の自動送信はアカウント停止の危険がある。文面を用意して、送信は人が押す。送ったら人が D 列を「連絡済み」、I 列に日付。
- 商品写真を AI で作らない。サンプル案の画像は「イメージ」と明記されたものだけを使う。
- 過去のクラファン商品のデザインを提供するとは書かない（クラファンはオリジナル設計が前提）。
- 相手の個人情報（個人の連絡先など）を、公開されている窓口以外から集めない。
