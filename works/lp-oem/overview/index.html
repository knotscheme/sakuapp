CRAFT OEM / OVERVIEW

革小物のロゴ入れOEMを、集客から納品まで。

お客様が見るLPと見積もり、社内の管理画面、タイの工場とのやり取り、お客様の確認画面までを、ひとつのサービスとしてつないでいます。このページから、すべての画面を確かめられます。

  • 下書きまで自動、送るのは人が確認して
  • タイの工場と、それぞれの言葉でつながる
  • 顧客情報を守る、高いセキュリティ設計
LPを見る管理画面を見る

※デモ版です。操作した内容は、見ている人のブラウザにだけ保存されます。

AUTOMATION

人がやるのは、確認して押すだけ。

問い合わせ・入金・ロゴの承認をきっかけに、システムが返信・見積・発注書の下書きまで自動で作ります。お客様に送る前と、工場に発注する前には必ず人が確認するので、間違いが外に出ません。

  • 見積の計算と見積書

    これまでExcelで単価・割引・税を計算して、見積書を作る

    このツールカラーと数量を入れるだけで、数量割引まで自動で計算。見積書も自動で作成

  • 問い合わせへの返信

    これまで一から文面を考えて書く

    このツール見積つきの返信がすでに下書きされていて、確認して送るだけ

  • 入金の確認

    これまで通帳やカード明細と、注文を見比べる

    このツール決済・振込を自動で照合。領収のお知らせも自動で送信

  • 入金の催促

    これまで期日を自分で追いかけて、メールを書く

    このツール期日を過ぎると、お願いのメールが下書きされて届く

  • ロゴ配置の確認

    これまで画像を加工して、メールに添付して送る

    このツール実物写真にロゴを重ねた配置イメージを自動で作成。承認もお客様の画面で

  • タイの工場への発注

    これまで英語やタイ語で発注書を作り、数を書き写す

    このツール承認されたら、カラー別の数量つきの発注カードを自動作成。最終確認すると、工場とのチャットにタイ語で届き、工場が「受けました」で返す

  • 進み具合と連絡

    これまで電話やLINEで、そのつど確認する

    このツール工場が工程を押すと管理画面に反映。連絡は相手の言葉で届く

※デモでは、入金は「カードで支払う（デモ）」のボタンで、メールは履歴に記録するだけです。本番では Stripe・銀行の入金データ・Resend とつなぎます。

FOR CUSTOMERS

お客様が見る画面

集客から見積もり、ロゴの確認まで。ログインなしで使えます。

  • LP（ランディングページ）

    見込みのお客様

    • ブランド名を入れて、実物の財布で刻印を試せる
    • 利益シミュレーター
    • 見積もり・相談のフォーム

  • 製品一覧

    見込みのお客様

    • 管理画面で登録した商品がそのまま出る
    • 丸のカラーピッカーで色を選べる
    • 選んだ色のまま相談に進める

  • 見積もりフォーム

    見込みのお客様

    • カラーごとに数量を入れられる
    • 合計の数で数量割引（30・50・100・300個〜）
    • あと何個で割引かも、その場で分かる

  • お客様の確認画面

    注文したお客様

    • メールの専用リンクで、自分の案件だけ見える
    • 見積の承諾・ロゴ配置の承認
    • 修正のお願いもここから

FOR THE TEAM

社内で使う画面（管理画面）

問い合わせから発送までを1つで管理。スマホでも同じように使えます。

  • 確認待ち（自動の下書き）

    オーナー・営業

    • 返信と見積・配置案・発注書を自動で下書き
    • 人は確認して「送信」を押すだけ
    • 工場への発注は最終確認のあと

  • 自動化の流れ（案件ごと）

    オーナー・営業

    • どこが自動で、どこが人の確認かが分かる
    • いまどこまで進んだか
    • 確認待ちへ、そのまま進める

  • ダッシュボード

    オーナー・営業

    • 進行中の案件・受注金額・期日
    • 数字を押すと、その一覧が開く
    • 工場からの新しい連絡

  • 案件ボード

    オーナー・営業

    • 段階ごとの列で、案件の今が分かる
    • スマホは段階のボタンで移動
    • 一覧（カード）表示にも切り替え

  • 案件の画面・ロゴ配置イメージ

    オーナー・営業

    • 「次にやること」を押すだけで進む
    • 実物の写真にロゴを重ねた配置イメージ
    • 書類とメールは自動で作られる

  • 見積（カラー別・数量割引）

    オーナー・営業

    • カラーごとの数量を入れると見積が変わる
    • 合計の数で数量割引が自動で入る
    • 原価・粗利も同じ画面で

  • 商品登録（SKU・バリエーション）

    オーナー・営業

    • カラー・サイズは先に登録して選ぶだけ
    • 組み合わせごとにSKU品番（自動作成も）
    • 画像10枚・動画も登録できる

  • 工場との連絡

    オーナー・営業

    • LINEのように、工場とのやり取りだけを並べる
    • どの商品の話かが写真で分かる
    • そのまま案件を開ける

  • 使い方マニュアル

    全員

    • 役割ごとに、読むべき章を案内
    • 工場の人にはタイ語で表示
    • 困ったとき・言葉の説明

SECURITY

お客様の情報を守る、高いセキュリティ設計。

お客様の情報と取引のデータを守るため、画面・データベース・通信・運用のそれぞれで、何重にも対策します。

  • デモで動いています

    役割ごとの権限

    見られる画面・押せるボタンを役割で分ける。権限を変えられるのはオーナーだけで、変更はすべて記録

  • デモで動いています

    工場には顧客情報を見せない

    工場の画面は担当の注文だけ。お客様の名前・連絡先・価格は表示しない

  • デモで動いています

    連絡先の伏せ字

    お客様の情報を見る権限がない人には、●●●● で表示

  • デモで動いています

    お客様は自分の案件だけ

    期限つきの専用リンクで、ほかのお客様の情報には届かない

  • 本番で導入予定

    データベース側でも守る（RLS）

    画面に不具合があっても、権限のないデータはデータベースが読ませない「行レベルの権限」

  • 本番で導入予定

    個人情報の暗号化

    電話番号・住所は AES-256 で暗号化して保存。万一データが漏れても読めない

  • デモで動いています

    2段階認証

    パスワードに加えて、スマホの認証アプリの6桁コードでログイン。役割ごとに必須にでき、間違いが続くと一時的にロック

  • 本番で導入予定

    操作の記録と通知

    CSVの書き出し・権限の変更・発注を記録。いつもと違う書き出しは、オーナーに通知

  • 本番で導入予定

    不正な送信を防ぐ

    フォームの連投制限、入力のチェック、ファイルの種類と大きさの確認、CSVの危険な文字の無害化

  • 本番で導入予定

    通信と画面の保護

    常に暗号化通信（HSTS）、読み込める先を限る設定（CSP）、他サイトへの埋め込みを禁止

  • 本番で導入予定

    秘密の鍵の管理

    APIキーは暗号化して保存。開発用のパソコンには本番の鍵を置かない

  • デモで動いています

    週に一度の脆弱性チェック

    毎週月曜に、使っている部品の弱点と、パスワードなど秘密の値の混入を自動で点検。問題があればすぐ通知し、部品の更新も毎週提案

  • 本番で導入予定

    事故への備え

    不審なアクセスの通知、バックアップ、事故が起きたときの対応手順を用意

※「本番で導入予定」の項目は、このデモ版には含まれていません。

FEATURES

主な機能

下書きの自動作成
問い合わせ・入金・承認をきっかけに、メールと発注書を自動で下書き。人は確認して送るだけ
ロゴ配置イメージ
お客様のロゴを、実物の写真に箔押し・素押しの見た目で重ね、修正の依頼と承認までやり取り
カラー別の見積と数量割引
色ごとの数量の合計で、単価が自動で下がる。あと何個で次の割引かも表示
SKUとバリエーション
カラー・サイズを登録しておき、組み合わせごとに品番。製品一覧には丸のカラーピッカー
工場とのやり取り
LINEのような画面。工場にはタイ語、日本には日本語で届く
役割と権限
オーナーだけが権限を変えられる。工場には顧客情報・価格を見せない
スマホで完結
下の小さなメニュー、押しやすい大きさ、文節で折り返す改行
