利用規約

最終更新日：2026年11月5日

この利用規約（以下「本規約」）は、knotscheme（以下「当方」）が提供するアプリ開発サービス「サクアプ」（以下「本サービス」）の利用条件を定めるものです。ご相談・お申し込みの前にお読みください。

第1条（適用）

本規約は、本サービスのご相談、お見積もり、開発、公開作業の代行、運用保守プランなど、当方とお客様との間の一切の取引に適用されます。個別のお見積もりや合意で本規約と異なる定めをした場合は、その定めが優先します。

第2条（サービスの内容）

本サービスは、お客様のご要望にもとづき、Webアプリ等のソフトウェアを開発してお渡しするサービスです。開発には、AIを使った作業支援を利用します。

第3条（ご相談とお見積もり）

  1. ご相談とお見積もりは無料です。
  2. 当方は、基本料金と追加機能の文字数等にもとづく金額、開発の範囲、納期の目安を記載したお見積もりをお出しします。
  3. お見積もりに記載のない作業・機能は、開発の範囲に含まれません。

第4条（契約の成立）

お客様がお見積もりの内容をご承諾いただいた時点で、個別の契約が成立します。

第5条（料金とお支払い）

  1. 料金は、お見積もりに記載の金額とします。
  2. お支払いは、開発の着手前に、クレジットカード（決済サービスStripeの画面）で行っていただきます。カードの一括・分割・リボ・ボーナス払いをお選びいただけます。分割払い等の手数料は、お客様とカード会社との契約によります。
  3. ドメイン・サーバー・外部サービスの利用料など、第三者に支払う費用は、お客様のご負担となります。これらの費用は、発生する前にお知らせし、ご了承をいただきます。
  4. 決済サービス（Stripe）の決済手数料は、お客様からStripeに直接お支払いいただきます。

第5条の2（お支払いが遅れた場合）

  1. お支払いの期日を過ぎた場合、当方はご連絡のうえ、開発や保守の作業を一時停止できます。
  2. 期日から30日を過ぎてもお支払いがなく、当方からのご連絡のあと14日以内にもお支払いがない場合、当方は契約を解除できます。
  3. お支払いが済むまでは、第11条のとおり納品物の権利は当方に残り、コードのお引き渡しも行いません。
  4. 期日を過ぎた金額には、法定利率による遅延損害金を請求することがあります。

第6条（仕様の変更）

契約の成立後に開発の内容を大きく変更・追加される場合は、内容に応じて別途費用が発生します。この場合、変更分を改めてお見積もりし、お客様のご了承をいただいてから進めます。ご了承のない追加料金を請求することはありません。

第7条（納品とご確認）

  1. 当方は、完成したアプリをお客様にお渡しし、動作をご確認いただきます。
  2. お渡しから14日以内にお申し出がない場合、または公開・運用を始められた場合は、ご確認が完了したものとします。

第8条（納品後の修正）

  1. 当方の原因による不具合（お見積もりの内容どおりに動かないもの）は、ご確認の完了後90日以内にお知らせいただいた場合、回数にかかわらず無償で修正します。
  2. お客様のご希望による小さな直し（文言・色・画像・配置など）は、ご確認の完了後90日以内に1回まで無償で承ります。ご希望の箇所は、1回のご依頼でまとめてお知らせください。
  3. 画面や機能の大きな変更・追加は、第6条にしたがい、内容に応じて別途お見積もりとなります。
  4. お客様による改変や、外部サービスの仕様変更による不具合は対象外です（運用保守プランで対応します）。

第10条（運用保守プラン）

  1. 運用保守プランは月額制で、不具合の対応、アップデート対応、動作チェック・バックアップ、管理画面で変更できない修正（月1回まで。翌月への繰り越しはできません）を含みます。
  2. 管理画面で変更できる内容（メニュー・画像・お知らせなど）は、お客様ご自身で変更していただきます。
  3. 運用保守プランに加入していない場合の修正は、1回3,000円からのお見積もりとします（第8条の無償修正に当たるものを除きます）。
  4. 新しい機能の追加は、追加機能として別にお見積もりします。
  5. 解約は第9条のとおりです。

第10条の2（月額型サービス）

「モバイルメニュー」「サロン予約」など、当方が用意したしくみをお店に合わせて設定し、月額でご提供するサービス（以下「月額型サービス」）には、第3条から第10条に加えて、次の定めが適用されます。本条と他の条項が異なる場合は、本条が優先します。

  1. 料金は、初期費用と月額料金です。初期費用は、お客様ご自身で設定する「セルフ」と、当方が設定を代行する「おまかせ」から選べます。お店専用の画面や機能を作る場合は、本サービスではなく、オーダーメイド開発として別途お見積りのうえご契約いただきます。月額料金には、サーバー代と保守（不具合の修正、アップデート、バックアップ）が含まれます。有料テンプレートは買い切りで、ご契約の期間中ご利用いただけます。金額は各サービスのページおよび特定商取引法に基づく表記に記載します。
  2. 月額料金は、ご利用開始月から毎月、クレジットカードに自動で請求します。ご利用開始月の料金は日割りしません。
  3. 最低契約期間はなく、いつでも解約できます。解約のお申し出があった月の末日で終了し、翌月以降の料金は発生しません。すでにお支払いいただいた月の料金の日割り返金はいたしません。
  4. 解約後は、メニュー・予約ページ等の公開を停止します。ご希望があれば、終了日から30日以内に、お客様のデータ（メニュー、顧客情報、カルテ等）をCSV形式でお渡しします。その後、データは削除します。
  5. 月額型サービスで作成した画面・プログラムは、複数のお店で共通して使うしくみです。第11条第1項にかかわらず、その著作権は当方に残り、お客様はご契約の期間中、ご自分のお店のために利用できます。お客様が用意した文章・写真・ロゴの権利は、お客様に残ります。
  6. お客様が月額型サービスに登録するお客様の顧客（来店者・予約者等）の個人情報は、お客様の指示にもとづく委託として取り扱い、サービスの提供以外の目的には利用しません。顧客から個人情報を取得する際の説明や同意の取得は、お客様が行うものとします。

第10条の3（先行モニター特典）

当方が先行モニターとして募集し、お申し込みを承諾したお客様には、次の条件で月額型サービスを提供します。

  1. おまかせ設定の初期費用を0円とし、有料テンプレートを1つ無料で提供します。月額料金は通常どおりお支払いいただきます。
  2. 契約期間は、ご利用開始月から6か月とします。6か月を過ぎたあとは、1か月ごとに自動で更新します。
  3. 最初の6か月のうちに解約される場合は、残りの月数分の月額料金をお支払いいただきます。6か月を過ぎたあとは、前条第3項のとおり月単位で解約できます。
  4. 解約のお申し出は、終了を希望する月（更新月）の前月末までにお願いします。期限を過ぎたお申し出は、翌月末での終了となります。
  5. お客様は、お店の名前・写真・ご感想を、導入事例として当方のWebサイト等に掲載することを承諾するものとします。掲載する内容は、事前にお客様に確認いただきます。
  6. 募集の店舗数は、各サービスのページに記載します。

第11条（権利の帰属）

  1. 納品物の著作権は、料金のお支払いが完了した時点で、お客様に移転します。
  2. 当方が以前から持っている汎用的なプログラムや、オープンソースのソフトウェアの権利は移転しませんが、お客様は納品物の利用に必要な範囲で自由に使えます。
  3. 当方は、お客様の許可がある場合に限り、納品物を制作実績として紹介することがあります。

第12条（禁止事項）

お客様は、次のいずれかにあたるアプリの開発をご依頼いただけません。該当が判明した場合、当方は契約を解除できます。

  • 法令や公序良俗に反するもの
  • 他人の権利（著作権・商標権・プライバシー等）を侵害するもの
  • 詐欺、なりすまし、不正なアクセスなど、他人に害を与える目的のもの
  • 反社会的勢力に関係するもの

第13条（秘密の保持）

当方は、ご相談や開発で知ったお客様の情報を、お客様の同意なく第三者に開示しません。ただし、法令にもとづく場合を除きます。

第15条（損害賠償）

当方は、必要に応じて本規約を変更できます。変更する場合は、効力が生じる日と内容を、このページで事前にお知らせします。すでに成立している契約には、お客様の同意がない限り、変更前の規約が適用されます。
